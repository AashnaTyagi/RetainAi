# RetainAI — API Reference

Full interactive documentation (request/response schemas, "try it out") is
auto-generated by FastAPI at `/docs` (Swagger UI) and `/redoc` once the
service is running:

```bash
uvicorn backend.main:app --reload
# http://localhost:8000/docs
```

This page covers the same endpoints with usage context and example calls.

## Authentication

None. This is a portfolio/demo API with no auth layer — add one (API key or
OAuth2, via FastAPI's `Security` dependency) before exposing it publicly with
real customer data.

## Endpoints

### `GET /health`
Liveness/readiness check. Returns `model_loaded: false` (still HTTP 200) if
the model artifacts failed to load — lets an orchestrator distinguish "the
process is up but not ready" from "the process is down."

```bash
curl http://localhost:8000/health
# {"status": "ok", "model_loaded": true}
```

### `GET /model_info`
Metadata about the currently loaded model.

```bash
curl http://localhost:8000/model_info
```

### `GET /metrics`
Test-set performance of the currently loaded model (accuracy, precision,
recall, F1, ROC AUC, sample counts).

### `POST /predict`
Predict churn risk for one customer. See `backend/schemas.py` →
`CustomerInput` for the full field list and validation rules (every
categorical field is a fixed enum; `TotalCharges` is cross-validated against
`MonthlyCharges`).

```bash
curl -X POST http://localhost:8000/predict \
  -H "Content-Type: application/json" \
  -d '{
    "gender": "Female", "SeniorCitizen": 0, "Partner": "Yes",
    "Dependents": "No", "tenure": 5, "PhoneService": "Yes",
    "MultipleLines": "No", "InternetService": "Fiber optic",
    "OnlineSecurity": "No", "OnlineBackup": "No",
    "DeviceProtection": "No", "TechSupport": "No",
    "StreamingTV": "Yes", "StreamingMovies": "No",
    "Contract": "Month-to-month", "PaperlessBilling": "Yes",
    "PaymentMethod": "Electronic check",
    "MonthlyCharges": 85.5, "TotalCharges": 427.5
  }'
```

```json
{"churn_probability": 0.8290325459067217, "prediction": "Churn", "priority": "Urgent — assign to a retention specialist"}
```

### `POST /predict_batch`
Same as `/predict`, for up to 500 customers in one call. Body:
`{"customers": [<CustomerInput>, ...]}`. Response includes each customer's
original list `index` so order/identity is never ambiguous.

### `POST /explain`
Everything `/predict` returns, plus:
- `top_contributions` — the 10 features that most influenced *this specific*
  prediction (SHAP values, with direction: `toward_churn` / `toward_staying`)
- `top_reasons` / `recommended_actions` — a grounded retention recommendation
  built from those drivers (see `src/recommendations.py`)

This is the endpoint a retention-focused UI should call, not `/predict` alone
— it answers "why" and "what to do," not just "what."

## Error Handling

- **422** — invalid input (bad enum value, missing field, failed cross-field
  validation, or an empty `customers` list for `/predict_batch`). The response
  body includes exactly which field(s) failed and why (standard FastAPI/
  Pydantic validation error format).
- **503** — model artifacts aren't loaded (run `python -m src.train` and
  restart the API).

## Rate Limiting / Quotas

None implemented. Add one (e.g. `slowapi`) before any public deployment.
